# 安全不变量

- Agent 不可执行任意 Shell 命令；网关和 Agent 双重强制白名单。
- Agent 仅接受验证 Ed25519 签名、节点 ID、配置版本和有效时间的命令。
- 未取得 SSH 服务器侧可信认证证明之前，不能关闭密码登录。
- 救援公钥保存在 D1 并不代表安装到 VPS；必须单节点手动启用。
- 关闭密码认证、恢复密码认证、快照恢复全部只允许明确的人工指令；不允许自动回滚。
- 未实现的 SSH 写功能应拒绝请求，不能回退到“只显示成功”。
- Linux 密钥文件不得覆盖用户现有 authorized_keys；安全文件操作必须检查 symlink、权限、SELinux、配置 Include/Match。
- 不能因 HTTP 200、Agent 报文受理或本地文件存在而宣称 SSH 登录成功。
- 本项目无法代替 VPS 提供商控制台救援。

**原型限制**：目前并不具备完整的远程 SSH 写安全机制。请勿在生产服务器使用。
